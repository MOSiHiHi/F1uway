# ⚙️ عملیات روزانه کار با مستطیل‌های چت و هستی‌شناسی (`operations.fa.md`)

- **شروع روز کاری:** `python3 scripts/devloop.py next` و `python3 scripts/devloop.py doctor`
- **انشعاب بدون هزینه توکن روی هر مفهوم:** `python3 scripts/devloop.py thread branch --span "PDA" --title "بررسی اتوماتای پشته‌ای"`
- **همگام‌سازی کدها و مستطیل‌های چت درون پلی‌بوک:** `python3 scripts/devloop.py sync-embeds && python3 scripts/devloop.py thread sync-md`
- **عبور از دروازه دوگانه (کد + یادگیری):** `python3 scripts/devloop.py gate`
