# 🚀 آنبوردینگ گام‌به‌گام انسانی (`00-onboarding.fa.md`)

1. ابتدا در ترمینال دستور `python3 scripts/devloop.py next` را اجرا کنید.
2. پلی‌بوک تسک جاری (`docs/human/playbooks/T1.1.fa.md` یا `phase-1.fa.md`) را باز کنید.
3. قبل از نوشتن کد، بخش `ZONE:HUMAN_INTUITION` را بخوانید و سوال پیش‌بینی در `ZONE:WORKSHEET` را جواب دهید.
4. اگر عبارتی برایتان مبهم بود، با `python3 scripts/devloop.py thread branch --span "عبارت" --title "سوال"` یک مستطیل چت فرعی باز کنید (اگر قبلاً در هستی‌شناسی باشد، با **۰ توکن** پاسخ فوری می‌گیرید).
