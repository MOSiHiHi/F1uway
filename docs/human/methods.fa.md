1. **چرخه چهارمرحله‌ای `Probe -> Plan -> Teach -> Practice` (از `LearnHarness`):**
   - **Probe:** کشف مرز دانش فعلی با اسلایدر اطمینان و بلند فکر کردن قبل از شروع درس.
   - **Plan:** ترسیم گراف پیش‌نیازها از نقطه فعلی تا هدف تسک.
   - **Teach:** الگوی `Predict -> Interactive Demo -> Check Question -> Repair Misconceptions` بدون لو دادن پاسخ نهایی.
   - **Practice:** بازیابی فعال در `notebook/cards.tsv` بدون بردن نام مفهوم در صورت سوال.
