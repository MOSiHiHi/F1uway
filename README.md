# F1uway — چهارچوب هم‌تکاملی توسعهٔ یادگیری‌محور و یادگیریِ توسعه‌محور
**The Co-Evolutionary Build-to-Learn (`B2L`) & Learn-to-Build (`L2B`) Meta-Framework**

> **فلسفه وجودی `F1uway`:**  
> ۱. **توسعهٔ یادگیری‌محور (`Build-to-Learn`):** در حال ساختن هر نرم‌افزار یا ابزاری، بر علم و معماری زیربنایی آن ۱۰۰٪ مسلط شو.  
> ۲. **یادگیریِ توسعه‌محور (`Learn-to-Build`):** در حال یادگیری هر دانش، کتاب یا مفهومی، ابزارهای واقعی و اجرایی آن را بساز.

## 🏗️ چهار ستون نوآوری در معماری `F1uway`

1. **گراف مستطیل‌های چت منشعب‌شونده (`Branchable ThreadBox DAG`):** هر پیام انسان، هوش مصنوعی یا تست ماشین یک گره تغییرناپذیر (`TurnNode`) درون یک مستطیل (`ThreadBox`) است. از هر پیام یا هر عبارت داخل پیام می‌توانید یک مستطیل جدید منشعب کنید، بدون اینکه زمینه اصلی (`Context`) آلوده شود.
2. **درونی‌سازی نمادها در هستی‌شناسی ضدتکرار (`Zero-Token Ontology Interning`):** اولین بار که روی عبارت $X$ منشعب می‌شوید، تعریف آن در `notebook/ontology/ONT_*.md` و ایندکس سایه SQLite ثبت می‌شود. در تمام متون و پروژه‌های بعدی، انشعاب روی $X$ (یا مترادف‌های فارسی/انگلیسی آن) در **۰ میلی‌ثانیه و با ۰ توکن API** از کش محلی پاسخ داده می‌شود و سوالات زاویه جدید فقط به صورت تفاضلی (`Delta Mode`) ارسال می‌گردند.
3. **ابرسندهای مارک‌داون دوچهره (`Zoned Dual-Faced Markdown`):** فایل‌های راهنمای انسانی ۵۰۰+ خط غنای آموزشی دارند، اما کامپایلر `devloop.py pack` فقط برش ۳۰ خطی `ZONE:CONTRACT` و `ZONE:GOLDEN_VALUES` را با پیشوند الفبایی قطعی (برای ۹۰٪ نرخ اصابت کش LLM) استخراج می‌کند.
4. **پیوند سه‌گانه `MJNexus` (رادار ابزار و ۱۷ دامنه) + `F1uxus` (هوش اسناد و خزانه دو-زمانی BiDi) + `F1uent` (هارنس کد و یادگیری `BKT + FSRS-6`):** اتحاد کامل هر سه پروژه خواهر در یک قالب واحد و قابل استفاده مجدد.

## ⚡ شروع سریع در ۳۰ ثانیه

```bash
# ۱. اجرای قطب‌نمای خودران انسانی
python3 scripts/devloop.py next

# ۲. مشاهده درخت مستطیل‌های چت و انشعاب‌های بدون مصرف توکن
python3 scripts/devloop.py thread tree

# ۳. مشاهده آمار رجیستری هستی‌شناسی و توکن‌های صرفه‌جویی‌شده
python3 scripts/devloop.py ontology stats

# ۴. اجرای دروازه دوگانه کیفیت (تست‌های مهندسی کد + گیت یادگیری و فلش‌کارت‌ها)
python3 scripts/devloop.py gate
```
